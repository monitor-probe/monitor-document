一个用 Rust 写的服务器探针。每台被监控的机器上跑一个 agent，把状态实时报给 hub；hub 提供管理面板和
一个公开状态页。

## 能看到什么

- **实时状态**：CPU、负载、内存、swap、磁盘、网速、TCP / UDP 连接数、进程数，默认每秒上报一次
- **流量**：总流量、按商家重置日计的月流量、今日流量，机器重启不清零。见[流量统计](/config/traffic)
- **延迟**：节点定时 TCP 连接指定目标，画出延迟和丢包。见[延迟监控](/config/ping)
- **到期**：记录价格与到期日，在线节点过期后自动顺延一个付款周期。见[节点](/config/nodes)
- **通知**：掉线、流量、到期、面板登录，推送到 Telegram 或 Webhook。见[通知](/config/notify)

负载告警、远程终端、插件不做，原因见[设计哲学](/guide/philosophy)。

## 三个部分

| 组件 | 装在哪 | 是什么 |
|---|---|---|
| **hub** | 主控机 | Rust + axum + SQLite 的单个二进制，面板、API 与公开状态页都在里面 |
| **agent** | 每一台被监控的机器 | 静态链接的单文件，读 `/proc`，经 WebSocket 上报 |
| **主题** | hub 里 | 公开状态页的外观，可替换。默认主题嵌在 hub 二进制里 |

```text
agent (Linux) ──WebSocket / JSON-RPC 2.0──▶ hub ──▶ 面板 + 公开状态页
```

连接由 agent 主动发起，被监控的机器不开放任何端口。NAT 后面的机器、只有 IPv6 的机器都能接入。
