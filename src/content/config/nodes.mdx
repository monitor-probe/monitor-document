**节点**页列出所有节点，拖动行可以排序，公开页按同样的顺序显示。每行右侧四个按钮：安装、编辑、续费设置、
删除。

## 编辑节点

| 设置 | 说明 |
|---|---|
| 名称 | 公开可见 |
| 分组 | 公开可见，见下文[分组](#分组) |
| 备注 | 只在后台显示 |
| 公开显示 | 关闭后节点只在后台出现，公开页和匿名接口里都没有它 |
| 离线通知 | 掉线超过宽限期时推送，见[通知](/config/notify) |
| 每月额度、计算方式、每月重置日、流量校正 | 见[流量统计](/config/traffic) |
| IPv4、IPv6、国家/地区 | 留空为自动，见下文[地址与国家](#地址与国家) |

公开页能看到名称、分组、国家、系统与硬件信息、实时状态、流量、价格和到期日；地址、hostname、备注和
token 只在后台。

删除节点会连同它的历史数据一起删除，不可恢复。机器上的 agent 要另外卸载，见[卸载](/install/uninstall)。

## 续费与到期

续费设置里填价格、货币、付款周期和到期时间。价格留空或填 0 显示为免费。

在线节点过了到期日会自动续期：hub 把到期日按付款周期往后顺延，直到晚于今天，并推送一条「已自动续期」
通知。

- 是否过了到期日按 hub 所在机器的时区算，hub 跨日后几秒内就顺延。Docker 部署没设 `TZ` 时按 UTC 算，
  东八区要到早上 8 点才跨日
- 只顺延在线的节点：离线节点过了到期日，可能真的到期了。离线期间过期、之后又连上的，在下一个整点顺延
- 付款周期为「一次性」的不顺延

公开页的「N 天后到期」「已过期」同样按 hub 的日期算，和访客所在地的日期可能差一天。到期提醒见
[通知](/config/notify)。

## 地址与国家

每个节点最多显示两个地址，一个 IPv4、一个 IPv6，取从外面能找到这台机器的那个：

- 网卡上的公网地址优先。有公网地址时不取内网、ULA 和 CGNAT 地址；IPv6 还避开隐私扩展生成的临时地址和
  换前缀后已过期的旧地址
- 网卡上只有内网 IPv4（NAT）时，显示 hub 看到的连接来源，即出口地址。为此这类机器连 hub 时先试 IPv4，
  5 秒连不上再换 IPv6
- 一个公网地址都没有时（hub 和节点在同一个内网），才显示内网地址

鼠标停在地址上会显示它的来源：网卡地址、hub 看到的出口，或手动填写。

国家按这个顺序挑地址去查：网卡上的公网 IPv4、网卡上的公网 IPv6、出口地址。机器自己的地址优先，因为出口
可能属于它前面的 NAT 或代理。内网地址不拿去查。

自动判断不对时，在编辑节点里手动填 IPv4、IPv6 或国家/地区（两位代码，如 `CN`），留空恢复自动。常见的
情况：

- 网关做了分流或透明代理：到 hub 的连接从代理出去，出口是代理的。节点没有公网 IPv6 时，国家也只能按
  代理出口算
- hub 只有 IPv6 入口：没有 IPv4 连接，NAT 节点的公网 IPv4 无从得知
- hub 前面是 Cloudflare 以外的 CDN：出口是 CDN 边缘的地址，按[反向代理](/install/reverse-proxy#3-透传-x-forwarded-proto-和-x-forwarded-for)
  里的 realip 配置换回访客地址。Cloudflare 不用配
- 一台机器有多个公网地址，想显示其中指定的那个

手动填的地址会一直显示，IP 变了要自己改。它只影响显示，不影响国家的判断。

## 分组

节点多了以后，公开页可以按分组切换。每个节点设一个分组，两个入口：

- **节点页工具栏的「分组」**：一次给多台设。填分组名，在下面的节点选择器里勾选节点，保存
- **编辑节点**：单台改

分组名最多 13 个字，留空即未分组。输入框会列出已有的分组，点选即可，避免手打出写法不同的同名分组。

<Note warn>
  分组名和节点名一样**在公开页可见**。只想自己看的信息写在备注里。
</Note>

「分组」对话框里的节点选择器可以搜索、按分组筛选，「全选」「全不选」只作用于列出来的节点，所以这几件事
都在这里完成：

| 要做什么 | 怎么做 |
|---|---|
| 给新接入的一批机器分组 | 筛选「未分组」，全选，填分组名，保存。还没有任何分组时不用筛选，直接全选 |
| 改分组名 | 筛选出这个分组，全选，填新名字，保存 |
| 解散分组 | 筛选出这个分组，全选，清空分组名，保存（按钮会变成「移出分组」） |

一次保存要么全部生效，要么一台都不改。勾选的节点里有一台刚在另一个标签页被删掉时，会提示刷新后重试，
其余节点也不会被改动。

### 在公开页上

分组的先后跟着节点顺序：拖动节点排序后，每个分组第一次出现的位置就是它的位置，不需要另外排。

默认主题在有分组之后，公开页顶部出现「全部 / 各分组 / 未分组」标签，上方的汇总（在线数、流量、实时网速）
只算所选的那一组。一个分组都没有时，公开页和没有分组功能时一样。第三方主题是否按分组显示，由主题自己
决定。

### 按分组选节点

通知页的**离线通知**卡片和延迟监控的**运行节点**用的也是这个节点选择器：先按分组筛选，再全选即可。两处都是
勾选完点保存才生效，一百台也只是一次提交。
